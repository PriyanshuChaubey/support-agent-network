# Escalation Process

If a suggested solution does not resolve the issue, escalate to a human
support engineer.

## Information to collect before escalating

- Workspace ID (found in **Settings → Workspace → General**).
- The exact report or export name affected.
- Timestamps of the last successful run and the first failed run.
- Any error message text, including error codes.
- Steps already attempted (e.g. "re-saved the schedule, checked destination
  auth").
- Browser/OS if the issue is UI-related, or client library + version if the
  issue is API-related.

## How to escalate

Use the **"Escalate to human"** button at the bottom of any support
conversation, or email support@flowlytics.example with the information
above. Escalated tickets are triaged within one business day.

## What NOT to include

Do not include API keys, passwords, or full credit card numbers in an
escalation. Support engineers never need raw credentials to investigate.
